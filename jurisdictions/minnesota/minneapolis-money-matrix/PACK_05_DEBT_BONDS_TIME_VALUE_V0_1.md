# Pack 05 — Debt, Bonds, and Time Value V0.1

Status: ECONOMICS_TEACHING_SPEC
Authority: false

Let:

~~~text
P = principal
r = periodic interest rate
n = number of periods
~~~

Simple teaching expression:

~~~text
Interest = P * r * n
~~~

Compounded future value:

~~~text
FV = P * (1 + r)^n
~~~

Present value:

~~~text
PV = FV / (1 + r)^n
~~~

Hard separations:

~~~text
BOND_AUTHORIZATION != BOND_ISSUANCE
BOND_ISSUANCE != CASH_SPENT
DEBT_OUTSTANDING != ANNUAL_DEBT_SERVICE
PRINCIPAL != INTEREST
BORROWING != REVENUE
LOWER_PAYMENT != LOWER_TOTAL_COST
~~~

Unknown instrument terms remain HOLD.
