## Core takeaway

The project was never dozens of disconnected civic experiments.

It is one citizen-centered operating system, expressed through different fixtures over time.

SSA deltas, congressional questions, blockchain replay, public-record audits, Replay America, CITIZEN_ROOT, and America.gov are treated here as distinct fixtures, instruments, documents, tables, routers, or interfaces that exercise the same underlying machine.

This reclassification does not erase or rewrite the historical names of the artifacts. It adds a higher-level project classification over them.

## Typed roles

### CITIZEN_ROOT

Subject + context root.

The human is the stable subject. Institutions are external system rails whose relevant public states may be observed, compared, receipted, and replayed.

### PUBLIC SYSTEM RAILS

SSA, VA, IRS, and other public systems.

Each system is a distinct rail. A system rail does not become the citizen's identity.

### AMERICA.GOV

Discovery + government-source routing surface.

```text
AMERICA.GOV != AUTHORITY
AMERICA.GOV != ADJUDICATOR
AMERICA.GOV != CITIZEN_IDENTITY_PROVIDER
```

### NAMED GUIDE

User-facing interface role descended from the Public Librarian concept.

```text
NAMED_GUIDE != HUMAN
NAMED_GUIDE != GOVERNMENT
NAMED_GUIDE != AUTHORITY
```

### COMPUTER WISDOM

State engine + difference engine + receipt engine.

It may organize, compare, classify, hold, and replay according to declared rules. It does not create governmental or legal authority.

### REPLAY

Temporal memory and deterministic reconstruction.

```text
REPLAY != INFERENCE
REPLAY != AUTHORITY
REPLAY != HISTORY_REWRITE
```
