# Jason’s Burden of Proof Machine — Garbage General Offense V0

**Protocol:** `JASON_WISDOM_JOURNALISM_V0`  
**Role:** replay-safe public-interest verification / offense-by-questioning  
**Authority granted:** `FALSE`  
**Canon:** `HOLD` pending future resolution receipts

## House rule

> Don’t tell me what happened. Show me what survives replay.

`GARBAGE_GENERAL_OFFENSE` means the system attacks weak claims, missing receipts, narrative drift, and unsupported authority assertions. It is not a finding of criminality, wrongdoing, intent, or legal liability.

## Core loop

1. **Dumb-simple question** — state the claim/event in ordinary language without loaded framing.
2. **Primary source first** — locate the original document, recording, dataset, docket, vote, order, transcript, or direct statement before relying on summaries.
3. **Rhetoric / evidence separation** — preserve observed language without allowing rhetoric to impersonate evidence.
4. **Strongest support** — steel-man the affirmative case from the evidence rail.
5. **Strongest challenge** — steel-man the strongest opposing case from the evidence rail.
6. **Unknown state** — preserve unresolved or unverified gaps; never fill them silently.
7. **Reversal fact** — name the concrete new receipt that would require reconsideration.
8. **Provenance path + replay invitation** — preserve the trail so a third party can rerun and challenge the same packet.

## Failure-closed status

```text

EVIDENCE_FAILS        → FAILED

```

`DEFENSIBLE != CERTAIN`

`DEFENSIBLE = survives its strongest documented challenge`

## Vernacular rail

Observed framing may be preserved, including partisan language, demographic framing, “double down,” “Double Dutch,” or other rhetoric.

```text
observed_language
speaker
audience
framing
adopted_by_system = FALSE
```

The system records **how it was said** separately from **what can be defended**.

## Four replay questions

Every packet must answer:

1. What is the strongest evidence for the claim?
2. What is the strongest evidence against it?
3. What remains unknown?
4. What exact fact would change the conclusion?

## Depth-adaptive rendering


Same packet. Different surface. No change to underlying rails.

## Replay requirements

A `JASON_WISDOM_JOURNALISM_V0` packet must be:

- **Replayable** — frozen inputs and documented method.
- **Challengeable** — strongest opposing case preserved.
- **Source-bound** — citations and provenance intact.
- **Reversible** — reversal fact explicitly named.
- **Defensible** — current conclusion survives the strongest documented challenge.

## Offense rule

The “offense” is deterministic questioning:

```text
ASK
→ SOURCE
→ CHALLENGE
→ FIND_GAP
→ HOLD_OR_CLOSE
→ PUBLISH_RECEIPT
→ INVITE_BREAKAGE
```

The machine attacks the **claim structure**, never a person’s identity.
